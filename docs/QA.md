## Dependency portability

The first GitHub CI run failed at `npm ci`: the lock generated by npm 11.6.2 omitted root `@emnapi/core@1.11.3` and `@emnapi/runtime@1.11.3` records needed by the optional WASM dependency tree. Its nested 1.11.1 packages satisfy a different exact dependency and cannot substitute for these root records.

The failure was reproduced with CI's npm 11.19.0. Regenerating the lock in an empty fixture with that installer restored both records and refreshed dependency classification flags; all existing package versions and integrity hashes remain unchanged. Clean installs passed in isolated Windows and Linux x64/glibc package-selection fixtures. Linux selection used `--ignore-scripts` because the host is Windows, so it is not a native Linux build result. The normal Windows install succeeded with npm's advisory about esbuild's undeclared `allowScripts` policy. No validation was disabled in CI. The actual GitHub rerun remains the authority for Linux build status.

## Size and performance scope

The static artifact is approximately 0.93 MB total before HTTP compression. The lazy 3D module is approximately 548 KB minified / 136 KB gzip; it loads only for pages with the scene. The bundler reports its standard >500 KB chunk advisory. This is the isolated Three.js renderer, not the initial page shell. No model or texture downloads; the former 17.7 MB GLB is excluded.

Fonts are self-hosted Latin WOFF2 subsets. Portrait is local WebP. Normal content is static HTML, readable before JavaScript. Animations respect reduced motion; 3D stops offscreen.

No Lighthouse score, field Core Web Vitals, real-iPhone frame-rate result or native Safari validation is claimed. Review those on the deployed candidate and physical devices before claiming performance targets.
